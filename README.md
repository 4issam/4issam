### 🚧 What I'm building

**[OrderGuard]** — a B2B SaaS fraud-intelligence platform for Algerian e-commerce merchants. In production.

| | |
|---|---|
| **Problem** | Cash-on-delivery fraud costs Algerian merchants on every failed delivery. There was no shared signal between stores. |
| **What it does** | A shared phone-number fraud-intelligence network, so a buyer who burned one merchant is flagged for the rest. |
| **Architecture** | Multi-tenant: per-store API keys, webhooks and data isolation. Universal webhook intake with drag-and-drop field mapping, so any store platform connects without custom integration code. |
| **Backend** | Node.js · Express · PostgreSQL (raw SQL, no ORM) · JWT auth · four-tier plan enforcement |
| **Admin plane** | Isolated admin panel on a separate JWT secret, staff accounts with per-store permissions, full activity logging |
| **Payments** | Chargily Pay (Algerian cards) |
| **Infra** | Railway · Vercel · Cloudflare |
| **Security** | Audited for auth bypass, plan isolation, SQL injection, XSS, IDOR, brute force and webhook replay — findings documented and remediated |
